# 月結小幫手：ERP 資料不出瀏覽器的 AI 月結交接包（POC）

把 ERP 匯出的「訂單明細」CSV 拖進網頁，在**你自己的瀏覽器**裡完成清洗、月結計算與假名化，產生只含「假名代號與比例」的 AI 交接包；AI 的回覆貼回網頁後，代號在本機還原成客戶名稱。

> **本專案所有資料皆為隨機捏造的虛構測試資料**，與任何真實公司、客戶、個人無關。統一編號刻意產生為檢查碼無效的號碼，Email 一律使用 `.example` 網域，地址為虛構路名。

## 使用方式

1. 開啟網址（或本機執行，見下方）。
2. 上傳 ERP 匯出的 CSV（範例：`data/synthetic_erp.csv`）。
3. 在「資料檢查」處理有問題的資料列（見下方說明）。
4. 看月結報表：毛利異常客戶、逐月毛利率與變化、逾期帳款、低於成本訂單、待處理資料。
5. 複製「AI 交接包」，貼到公司核准的 AI 工具。
6. 把 AI 的回覆貼回網頁，按「還原代號」。

## 操作引導

頁面頂端固定一條步驟列（上傳檔案、檢查資料、看報表、交給 AI、貼回還原）與「下一步」提示條。提示條依目前狀態說明該做什麼，並用光圈與彈跳標籤指出下一個要按的地方；有待處理資料時，可以選擇先處理或先看報表，不強制。提示條可以按「關閉提示」關掉。

- 動畫全部是 CSS，不使用外部套件；系統設定「減少動態效果」時，動畫會自動改成靜態外框。
- 「現在是哪一步」的判斷是獨立的純函式（`src/guide.js`），有自動測試（`tests/guide.test.js`）。
- 引導狀態只存在分頁記憶體，不使用任何瀏覽器儲存。

## 資料檢查與修正

上傳後，問題依等級分三類，每一列都標出位置、訂單單號、客戶、原本的值與約影響收入：

- **需要你處理**：缺少必要計算欄位（統編空白、缺單位成本、數量或日期無法判讀等）。這些列目前沒有納入任何數字。可以直接在畫面上補值並按「套用修正」，報表立刻重算，並顯示修正對總收入與毛利率的影響；也可以「確認不納入」。
- **提醒**：不影響收入與成本，例如帳款到期日空白（無法判斷逾期）。
- **系統已自動處理**：單價或金額空白，依題目口徑回推，列出算式供抽查。

所有修正只存在分頁記憶體。可以下載 `原檔名_修正後.csv`（保留所有資料列、格式與原檔相同）與 `原檔名_修正紀錄.csv`（時間、行號、欄位、原值、新值），也可以逐列或全部還原。報表與交接包都會標示「含 N 列人工修正」，交接包只帶筆數，不帶任何值。

## 在本機跑起來

不需要安裝任何套件、不需要金鑰。需要 Python 或任何靜態檔案伺服器：

```bash
python -m http.server 8765 --bind 127.0.0.1
```

然後瀏覽 `http://127.0.0.1:8765/`。

執行自動測試（需要 Node.js 18 以上）：

```bash
npm test
```

## 資料安全設計

- 純靜態網站：沒有後端、沒有 AI 呼叫、沒有金鑰、沒有分析追蹤、沒有外部資源。
- `index.html` 內的內容安全政策（CSP）設定 `connect-src 'none'`、`default-src 'none'`、`form-action 'none'`，瀏覽器會直接擋下任何對外連線。
- 資料只存在分頁記憶體，不使用 localStorage / sessionStorage / cookie。假名對照表每次上傳重新隨機編排，兩個分頁互不相通。
- 交接包只含：代號（C- 客戶、O- 訂單、P- 品項、R- 業務員）、百分比、百分點、天數、筆數、規模級距、提示文字。不含：名稱、統編、聯絡人、電話、Email、地址、備註、品名、金額、單價、成本、數量。
- 畫面上的交接包、複製內容、下載內容都來自同一個字串；複製前會再比對一次，不一致即拒絕。
- 頁面標示禁止瀏覽器「翻譯此頁」（避免畫面上的真實名稱被送到雲端翻譯）；貼回框關閉拼字檢查與自動完成。
- 還原後含真實名稱的內容只顯示在畫面上，刻意不提供「複製還原結果」，避免真名進入系統剪貼簿或雲端剪貼簿同步。
- 貼回的 AI 回覆一律以 `textContent` 顯示，不會被當成 HTML 或程式。對照表沒有的代號會標紅，不硬還原。
- 自動檢查：產生交接包後，程式會拿檔案中所有原始值逐一比對，並檢查數字只有彙總形式。

## 計算口徑

- 收入 = Σ 未稅金額；成本 = Σ 數量 × 單位成本；毛利率 = (收入 − 成本) ÷ 收入；收入為 0 顯示「不適用」。退貨（負數列）直接沖減。
- 結帳基準日預設為檔案中最晚單據日期所在月份的最後一天，可在畫面修改。只納入單據日期不晚於基準日的資料。
- 逾期 = 到基準日仍無收款日期（或收款日晚於基準日），且帳款到期日早於基準日；只計正數應收。
- 同一統一編號視為同一法人，合併不同客戶代號與名稱寫法。
- 缺少必要計算欄位、統編空白、數量為 0 且無法回推單價的資料列，列為「待處理」，不納入計算，也不補零。
- 所有數字由程式計算，AI 只負責解讀。

## 目錄

```
index.html, style.css     網頁
src/csv.js                CSV 解析（BOM、引號、換行）
src/clean.js              清洗：日期（西元/民國/ISO）、全形數字、回推單價與金額、問題分級、單列重新判定
src/calc.js               月結計算
src/pseudo.js             假名化、交接包、自我檢查、還原
src/guide.js              操作引導：目前步驟與下一步提示（純函式）
src/app.js                畫面與事件
tools/gen_data.py         假資料產生器（固定種子，可重現）
data/                     範例假資料、標準答案（*.truth.json）、驗收答案（*.answer.md）
tests/                    自動測試（對照產生器獨立算出的標準答案）
```

## 重新產生假資料

```bash
python tools/gen_data.py                                   # data/synthetic_erp.csv（種子 20261109）
python tools/gen_data.py --seed 7 --out data/blind_test_a.csv
```

同一個種子一定得到同一份檔案。

自動測試會對 `data/` 底下所有存在的資料檔逐一驗證。repo 只附 `synthetic_erp.csv`；要用另外兩份不同內容的檔案做盲測，執行 `npm run gen-blind` 重新產生（種子 7 與 20260），再跑 `npm test`。埋入的髒資料與業務異常列在 `data/synthetic_erp.answer.md`。

## 已知限制

- 目前只支援 CSV；Excel 請先另存為 CSV UTF-8。
- 假名化不是絕對匿名：客戶家數少時，規模級距與毛利走勢仍可能被熟悉內情的人推測身分。
- 無法阻止使用者把交接包貼到未核准的 AI 工具，這需要公司規範配合。
